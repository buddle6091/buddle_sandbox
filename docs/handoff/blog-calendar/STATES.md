# STATES — 상태·예외 전수 (참조 4a~4k)

> 공통 규칙: 스켈레톤은 bg/muted 단색, 투명도 .6↔1 펄스 1.2s, **300ms 안에 응답하면 띄우지 않음**, 도착 시 크로스페이드 170ms. 빈 상태 = 제목 16/700 + 설명 body-sm muted + 행동 1개(점선 자리표시, 아이콘 없음). 오류 = Badge warning + 「다시 시도」 primary + Mono caption 디버그(GET /posts · 503). 토스트 = 하단 중앙 gray/900 불투명 radius/lg 48h, 4s, 액션 1개, 아래서 8px 300ms. 파괴적 행동만 danger 버튼.
