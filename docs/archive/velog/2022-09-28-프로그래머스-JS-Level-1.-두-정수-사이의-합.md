#### 문제
```javascript
function solution(a, b) {
    var answer = 0;
    return answer;
}
```
---
```
💡 예전에 많이 봤던 1 에서 100까지의 수의 합은 무엇인지 확인하는 내용과 같은 문제이다. 여기서 1 ~ 100까지의 합계는 (1 + 100) * (100 - 1 + 1) / 2
```
---
#### ✨ 풀이 방법
```javascript
function solution(a, b) {
  // a, b 중에 뭐가 큰 수 인지 모르니 절대값으로 정수로 환원
    return (a + b) * (Math.abs(a - b) + 1) / 2;
}
```
