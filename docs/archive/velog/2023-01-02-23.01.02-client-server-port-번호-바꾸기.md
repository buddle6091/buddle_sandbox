> 23년 토끼띠의 해가 밝았습니다. 
항해 99 9기 활동을 마치고 번아웃이라는 핑계를 대며 그동안 만나지 못했던 사람들, 그리고 오랫만에 해보는 침대에서 뒹구는 등의 리프레쉬를 오랫동안 해버렸네요. 
이젠 컨디션 조절하면서 다시 개발에 힘써보려고 합니다!

## Client server port number

우선 백엔드처럼 클라이언트 또한 자체 서버를 운용한다는 사실을 알고 계실 것이라고 한다. 
우리 프론트엔드 개발자들은 가상 서버를 열어 해당 기능들이 잘 작동하고 있는지 확인하는 용도로 사용한다..

처음에 포트 번호는 8080
![](https://velog.velcdn.com/images/buddle6091/post/d826a234-3d2b-4bad-b719-8c82edf0c7a3/image.png)

`package.json`에서 scripts 부분의 serve 부분을 살짝 손보면 된다. (해당 프로젝트는 vue로 제작되었습니다.)
![](https://velog.velcdn.com/images/buddle6091/post/581a27a2-9ec3-484e-ae73-48576ea8812f/image.png)

바로 `vue-cli-service serve`  뒤에 `--port 3000`을 붙여 포트를 8080 -> 3000으로 변경한다.

그리고 `npm run serve` 으로 실행을 하면?

![](https://velog.velcdn.com/images/buddle6091/post/f6617003-7c6c-4559-9fbd-7866d23745c5/image.png)

으로 사용이 가능해진다!
