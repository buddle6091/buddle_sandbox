### 일단 하소연 한번 해보고 싶어요 글이라도.. 😥
현 시즌 나는 취업준비생의 `발단 - 전개 - 위기 - 절정 - 결말` 의 마무리 단계인 결말에 해당하는 기업 지원단계에 놓여있다.. (절정일지두 ㅎ) 그렇지만 이 `결말`이라는게 국어책에서 배웠던 갈등단계들이 모두 해소되고 이야기가 종결되는 단계라고 하지만 현재 나는 `위기` 상태이다! 
왜냐하면 물론 아직 많이 넣진 않았지만 그래도 찔끔찔끔 넣었던 회사들에서 모두 서류 탈락이라는 결과만 받아들이는 중이기 때문이다. 
이게 정말 마음이 꺾인다는게.. 비록 신입 주제에 연차가 있는 회사를 지원한 것이 큰 이유이긴 하지만, 정말 내가 개발자로써 흥미가 생기지 않는 사람이라 팀원으로 받아들이기 부적절한가 라는 생각이 든다. 
> 22년도 희대의 띵언 DEFT 왈 : "중요하건 꺾이지 않는 마음"

이랬지만, 조금씩 꺾이고 있는 것 같다. 이러다 자존감까지 결여된 사람이 되면 어떡하지라는 생각도 들기도 한다. 하지만 결국 이 위기 또한 금방 지나가겠지?

---

아무튼 거두절미 하고 해당 글에 대한 이야기를 본격적으로 해보도록 하겠다. 

위에 하소연에서 현재 나는 이력서를 넣고 있는 단계라고 하였다. 개발자들은 기본적인 이력서를 만들어 여러 기업에 자신의 능력을 쉽고 간결하게 읽을 수 있도록 한다고 한다. 그렇기에 정말 나를 자랑을 하고 싶어도, 읽는 사람들이 지루하지 않게 최대한 가독성 있으면서, 핵심내용만 잘 녹여내야한다.
그래서 어느정도 만들어졌다 생각하고 지원을 하고 있었는데, 몇 기업에서 이런 문구가 이력서 `필` 사항에 써있었다.
> 해당 프로젝트에서의 기여도가 얼마나 되는지 이력서에 써주세요~


개인프로젝트라면 내 혼자 만든거니 기여도는 100%이다. 하지만 협업프로젝트라면 나 이외의 다른 개발자 분들과 만든 것이니, 분명 총 백분율에서 퍼센테이지로 나누어 떨어질 것이다. 
기존의 나의 이력서에서는 기여도는 넣지 않고 해당 프로젝트에서 핵심활동만을 기록해놓았으니 해당 내용을 추가로 기입을 해야만 했다. 하지만 이게 말만 기여도지, 해당 근거를 어디서 얻지라는 생각이 먼저 들게 되었다. 아무래도 발언에 있어서 뒤받침해주는 타당한 자료들이 있어야지 해당 내용이 신빙성을 얻게 되기 때문인 것 같다.

그래서 구글링을 하던 결과 이런 친구를 발견하게 되었다.

## Github Insights
정확히 말하자면 해당 프로젝트 repository 안에 있는 Insights 컬럼 부분이다.
하단의 이미지를 자세히 보면 `Settings` 옆에 `Insights`라는 부분을 발견할 수 있다.
![up](https://velog.velcdn.com/images/buddle6091/post/1dea25c7-f5d6-4835-9f92-6ac7f6189cf1/image.png)

해당 부분을 클릭하게 되면 통계페이지를 볼 수 있는데 첫 페이지를 보게되면 좌측 바에선 Pulse라고 보이고 중앙에는 기간과 PR 기록을 볼 수 있다. 
이곳에서 최대로 볼 수 있는 기간은 딱 1주일이다.
![통계](https://velog.velcdn.com/images/buddle6091/post/752eb756-6a7d-4f30-942d-9f2e8f4a62d8/image.png)

다음은 기여도라고 볼 수 있는 커밋 및 코드량이 나와있는 `Contributors` 부분이다.
해당 부분을 클릭하면 그래프로 전체 프로젝트 기간에 작성된 코드 및 커밋량을 볼 수가 있다.

![](https://velog.velcdn.com/images/buddle6091/post/4b29e972-62ea-4592-8eca-2fbf35b360c3/image.png)


### 여기서 느낀점..!

그렇다면 기여도라고 한다는 것이 과연 `코드량과 커밋량으로만 판단할 수 있느냐`인 것이다. 위의 프로젝트는 기획부터 배포까지 모두가 참여한 프로젝트이기에 여러 부분에서의 요소 또한 배제할 수 없다는 것이 개인 생각이다. 일단 깃허브 자체에서 남은 기록은 이것밖에는 없는 듯하다. 
(물론 추후에 더 찾아보면 무언가 나올지도 모르지만..)
그래서 과연 기여도란.. 특히 개발자에게 있어서 순수 코드작성의 빈도 등의 기여도를 뜻하는 것인지가 무척 궁금하다.
