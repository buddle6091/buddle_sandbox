역시 환기 한번 시키고 싶을 때는 코테 풀기만한게 없는 것 같기도..? 

## 프로그래머스 LV 2. 호텔 대실

### 문제

![](https://velog.velcdn.com/images/buddle6091/post/25ffb025-df48-4228-bd8f-cbbc766bc82b/image.png)



### 제한사항

- 1 ≤ book_time의 길이 ≤ 1,000
- book_time[i]는 ["HH:MM", "HH:MM"]의 형태로 이루어진 배열입니다.
- [대실 시작 시각, 대실 종료 시각] 형태입니다.
- 시각은 HH:MM 형태로 24시간 표기법을 따르며, "00:00" 부터 "23:59" 까지로 주어집니다.
- 예약 시각이 자정을 넘어가는 경우는 없습니다.
- 시작 시각은 항상 종료 시각보다 빠릅니다.


### 입출력 예

![](https://velog.velcdn.com/images/buddle6091/post/d49665f8-9880-4959-b2e5-71484da428e7/image.png)


그러니까 이런 형태다. 입실을 하게 되면 퇴실도 해야되는 것은 당연지사. 그런데 퇴실하고 바로 입장이 가능한게 아니라 10분의 인터벌이 주어진다는 소리다.

book_time 첫 번째 예시를 보면 `[["15:00","17:00"], ["16:40", "18:20"] ... ]` 인 부분의 결과가 3개 즉 최소 객실의 수가 3이라고 한다.

우선 이 배열들이 시간대 순으로 나열되지 않았음으로 시간대별로 놓고 생각을 해보면, 14:10 ~ 19:20, 14:20 ~ 15:20, 15:00 ~ 17:00 의 시간대가 겹치니 최소 3개의 방이 필요하다. 그 후 16:40 ~ 방은 15:20에 이미 나온 방이 있으니 그 방을 사용이 가능하고, 18:20 ~ 방은 14:10 or 15:00 방이 이미 나와 있으니 둘 중 하나로 사용이 가능하다.

이런 형식의 알고리즘이 구현되어 있는 것을 확인할 수가 있다.

우선 시간 계산을 위해서 `string` 형식의 배열 데이터를 `number`로 전환하고 동시에 `시` 와 `분` 으로 나눠볼 생각이다. 그래서 기존의 정답을 요하는 solution 함수가 아닌 변환을 해주는 함수를 하나 만들어보자.

#### 시, 분 분할 함수 만들기

```js
const siAndBun = (time) => {
  const [si, bun] = time.split(":").map((x) => +x);
  return si * 60 + bun; 
}
```

time 이라는 매개변수를 받아 시와 분으로 나눠서 숫자형으로 변환해주는 `siAndBun` 함수를 생성해준다. 그리고 그 안에 시와 분을 받아야 되는데 해당 2차원 배열의 안쪽을 보게 되면 문자열로 구분지어 있으니 `:` 기준으로 분리한 수 Number 형태로 형변환 해줘야 한다.
그래서 [시(si), 분(bun)] 형태의 새로운 숫자 배열로 반환하기 위해서 2번째 줄과 같이 작성을 하였다.
그 후 시간 계산에 용이하기 위해 분 형태로 바꿔준다.

#### 문제 본격적으로 해결해보기

```js
function solution(book_time) {
  const timeArray = Array.from({length: siAndBun('23:59') + 10}, () => 0);
  
  book_time.map((time, idx) => {
   const [checkIn, checkOut] = time;
    let start = siAndBun(checkIn);
    const end = siAndBun(checkOut) + 10;
    
    for(start; start <= end; start++) {
     timeArray[start]++; 
    }
  });
 return Math.max(...timeArray) ;
}
```

위에서 만든 함수를 가지고 본격적으로 문제를 해결하려고 한다. 먼저 이 `solution` 이라는 함수는 문제에서 제공한 `book_time`이라는 매개변수를 가지고 있다. 
그리고 timeArray라는 변수로 `Array.from` 메서드의 최대 길이를 구하여 얕은 복사를 진행하는 역할을 만들어낸다.

그리고 매개변수로 받은 book_time을 map을 돌려, 2차원 배열의 depth level 2의 배열의 0번째 인덱스가 들어가고 1번째 인덱스가 나오는 배열이라는 것을 만들고 해당 변수들을 위에서 만든 `siAndBun`으로 분으로 변환한다. 
그 후 시작에서 끝까지 시작점 만큼 증가시킨 함수를 가지고 최소의 객실 수를 구하면 된다.

그런데 10분 인터벌을 고려하여 + 10을 하였는데 부분에 오류가 발생한다.

![](https://velog.velcdn.com/images/buddle6091/post/40774306-54a6-47bc-bcb0-5a6f0a0cb2fb/image.png)

그 이유는 이러하다. 10시 10분에 체크아웃을 하고 10시 20분에 들어갈 예정이다. +10을 하게 되면 체크인 시간이 다가와도 아직 청소가 끝나지 않아, 10시 10분 방을 이용을 못하기에 결과값이 2가 나와 기댓값과 다르게 되는 것 같다. 세부적으로 이해한다면 이 10분이 9분 59초의 10분과 10분 59초까지의 10분의 정의로 구분되는 것이라고 생각한다. 만약 아니라면 댓글을 달아주시면 좋을 것 같다!

그래서 +9로 하게 된다면 테스트 2번도 해결이 된다.
