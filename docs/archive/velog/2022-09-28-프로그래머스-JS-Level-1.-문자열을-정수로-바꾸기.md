#### 문제
```javascript
function solution(s) {
    var answer = +s;
 
    return answer;
}
```
---
```
💡 이 문제 같은 경우는 많이 간단하다. 받은 s라는 문자열을 숫자로 변환하는 Number()나
parseInt(), 그리고 정수로 변환이 가능한 문자열에 부호나 간단한 연산등을 넣어 정수로 
변환이 가능하다.
```
---
#### ✨ 풀이 방법
```javascript
function solution(s) {
  return +s;
}
```
