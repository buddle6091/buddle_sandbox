#### 문제
```javascript
function solution(numbers) {
    var answer = -1;
    return answer;
}
```
---
```
💡 0 ~ 9 까지 모든 수의 함은 45이다. 결국 답을 구하려면 45 에서 numbers의 변수들의 합을 뺀 것이 문제가 바란 값이다.
```
---
#### ✨ 풀이 방법
```javascript
function solution(numbers) {
  	let arrayAdd = 0;
  	
  	numbers.map(x => {
     	arrayAdd += x;
    });
  return (45 - arrayAdd);
}
```
