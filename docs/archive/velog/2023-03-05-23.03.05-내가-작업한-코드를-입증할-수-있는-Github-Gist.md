## Github Gist 를 어떻게 접하게 됬느냐하면

요즘 이쪽 직종 회사들에 입사지원을 할 때 보통, 이력서와 자신이 그동안 만들었던 프로젝트를 정리한 포트폴리오를 제출하라고 요구하는 경우를 발견할 수 있다.

아마 내 단에서는 개발자가 어떠한 방식으로 코드를 쓰는지를 일일이 github 저장소에서 확인할 필요없이, 일부 부분을 발췌하여 gist에 올려두면 gist url을 통하여 인사 담당관이 쉽게 지원자의 역량을 확인하기 위하여 많이 이용하는 것으로 보인다.

그럼 이번에 Gist를 올리는 과정을 정리해보려고 한다.

---

# Github Gist

Github Gist 의 [공식 홈페이지](https://gist.github.com/)를 가보게 되면
> "Instantly share code, notes, and snippets"

이라는 문구가 쓰여져 있는데 한국어로는 `코드, 노트 및 스니펫을 즉시 공유한다` 라는 의미이다.

위에서 언급했듯 빠르게 코드를 확인하기 위해서 코드의 문단 혹은 컴포넌트 단위를 URL 로 설정하는 기능을 제공하는 것이 이 `Gist`이다.


## Gist를 한번 등록해보자

![](https://velog.velcdn.com/images/buddle6091/post/eea13605-ca53-431a-b903-16ac8f522b69/image.png)

위에 Gist description 부분은 해당 코드에 대한 설명 분을 올리는 부분으로 보인다. 간단하게 이 코드가 이렇게 만들어졌어요~ 라고 말이다.

다음은 해당 코드가 어떤 파일로 설정이 되어있는지 파일명을 적고, 하단 큰 text area 부분에는 코드를 작성하면 된다.

Add file를 누르면 해당 gist에 부가적으로 필요한 코드 스니펫을 추가로 작성이 가능하다.

다 작성된 코드는 secret, public 둘 중 하나로 선택하여 생성하면 되는데, 이때 gist는 전부 무료라서 secret을 고를 시에 금액이 나오는 것은 아닌지 걱정하지 않아도 된다고 한다.

![](https://velog.velcdn.com/images/buddle6091/post/8e0d9f10-5b28-4588-b61a-0350190c8397/image.png)


다 작성하고 등록하면 이러한 페이지가 생성이 되고 이 페이지 링크를 gist link로 활용하여 사용하면 된다. 

아, 이 link는 검색엔진으로 검색이 된다. 검색되고 싶지 않다면 public에서 secret으로 설정해 놓자.
